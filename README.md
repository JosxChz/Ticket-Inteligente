Entendido, aquí tienes una versión limpia y técnica del README.md para tu proyecto, eliminando todos los elementos gráficos o decorativos:Smart Ticket and Loyalty System (Solana)Este programa es un contrato inteligente desarrollado con el framework Anchor (Rust) para la red de Solana. Su objetivo es gestionar el ciclo de vida de tickets para eventos, integrando un sistema de fidelización de usuarios basado en niveles (Tiers) y recompensas por asistencia.Funcionalidades Principales1. Gestión de EventosEl contrato permite a los creadores definir eventos con parámetros específicos:Identificador único (ID).Nombre del evento.Fecha (formato Unix Timestamp).Hash de ubicación para verificación externa.Precio base en Lamports.Capacidad máxima de asistentes.2. Adquisición de Tickets y ReferidosLos usuarios pueden comprar tickets, y el programa realiza las siguientes acciones:Verifica la disponibilidad de cupos.Aplica descuentos automáticos según el nivel (Tier) del comprador.Registra opcionalmente una dirección de referido para futuras bonificaciones.Incrementa el contador de ventas del evento y actualiza los puntos del usuario.3. Validación de Asistencia y PuntualidadEl proceso de check-in valida que el ticket esté activo y pertenezca al usuario. Además:Verifica si el usuario llega en la ventana de tiempo permitida (30 minutos antes del evento).Otorga puntos base por asistir y puntos de bonificación por puntualidad.Actualiza el nivel del usuario de forma automática si cumple con los requisitos.Estructura de Datos (Cuentas)Evento (PDA)Almacena la configuración del evento. Semillas: ["evento", evento_id].Ticket (PDA)Representa la propiedad de una entrada. Semillas: ["ticket", evento_id, usuario_pubkey].TierUsuario (PDA)Registra el progreso del usuario en el ecosistema. Semillas: ["tier", usuario_pubkey].Lógica de Niveles y DescuentosEl sistema clasifica a los usuarios en tres categorías según su actividad:NivelRequisitos (Asistencias / Puntos)Descuento AplicadoBronze (1)Nivel inicial0%Silver (2)3 asistencias y 100 puntos15%Gold (3)5 asistencias y 200 puntos30%Instrucciones del Programacrear_evento: Inicializa la cuenta del evento y define sus reglas.comprar_ticket: Crea la cuenta del ticket y procesa el pago con descuento.validar_asistencia: Marca el ticket como usado y sube de nivel al usuario si corresponde.ver_estado_ticket: Función de utilidad para consultar datos del ticket y nivel del usuario.obtener_descuento: Retorna el porcentaje de descuento actual del usuario.ver_eventos: Muestra la información pública de un evento específico.Requisitos de DesarrolloAnchor Framework v0.29.0 o superior.Solana CLI tools.Rustc v1.75.0 o superior
